## Projects

**[Network Assistant](https://github.com/taylorjgay/network-assistant):** A Python MCP server and React dashboard for managing a home network through Claude or a web UI. Reverse-engineered local APIs for a TP-Link dual-WAN router, Deco mesh nodes, and Pi-hole. 39 MCP tools, 198 mocked tests.

**Home Automation Server** (private repo): A self-hosted stack on bare Ubuntu and Docker Compose, unifying 40+ devices across seven platforms behind one local API, with Caddy handling hostname routing. The 2.5 GbE NIC shipped with a driver bug that stalled the link every few minutes; fixed by building the vendor driver from source via DKMS and blacklisting the kernel default at boot.
